Backend «Бібліотека Обрій»

Цей розділ генерується JSDoc безпосередньо з JavaScript-коду backend.

Основний потік виконання:

HTTP route -> input validation -> service -> repository -> PostgreSQL
  • Routes приймають HTTP-запит, перевіряють сесію та роль.
  • Input перевіряє й нормалізує вхідні поля.
  • Services реалізують бізнес-правила.
  • Repositories виконують SQL і транзакції.
  • Jobs запускають службові процедури, які не прив'язані до одного HTTP-запиту.

Окремий інтерактивний опис HTTP-контракту знаходиться в розділі OpenAPI / Swagger UI на головній сторінці документації.
